# Coco

React Native Expo blank app. Uses **Yarn** as the package manager.

## Setup

```bash
yarn install
```

## Run

- **iOS:** `yarn ios`
- **Android:** `yarn android`
- **Web:** `yarn web`
- **Expo dev server:** `yarn start`

## Project structure

- `App.js` – main app component
- `app.json` – Expo config (app name: Coco)
- `assets/` – icons and splash
